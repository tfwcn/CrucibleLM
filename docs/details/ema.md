# EMA：影子权重的平滑冠军

> 一句话：训练时同步维护一份滑动平均权重，又稳又准，评测和冠军都用它。

## 痛点

训练后期的权重在最优点附近抖（batch 噪声），单步 eval 忽高忽低，
"冠军是哪一步"全看运气。EMA（指数滑动平均）是时间的平均：
`shadow = 0.999·shadow + 0.001·新权重`，抖动被抹平，泛化还常更好。

## 直觉

射击打 10 发，取平均弹着点比取最好的一发更能代表水平。EMA 就是那个
平均弹着点——它没见过任何"幸运 batch"，只见过时间。

## 原理

```
每 N 步：ema = decay·ema + (1-decay)·model   # decay=0.999
评测：ema_val = eval(ema)                     # 影子保持 eval 模式！
冠军：按 ema_val 选，存影子权重
```

三处细节决定成败：

1. **影子全程 eval 模式**：`evaluate()` 尾巴有个 `model.train()`，
   传影子进去必须关掉（`restore_train=False`），否则 dropout 把影子评测
   变成噪声——修过，单测锁了；
2. **一致性 loss**（可选，`--ema-weight 0.05`）：主干 logits 向影子对齐的 MSE，
   影子 no_grad，不占梯度，相当于"别跑太偏"的缰绳；
3. **冠军存影子**：`best/` 里是 EMA 权重，不 Raw 权重——上线、续训都从它起。

## 我们的实现

- 文件：`scripts/train_local_llm.py`（影子构建/同步/评测/冠军四件套）
- 开关：`--ema-every 10`、`--ema-decay 0.999`、`--ema-weight 0.05`
- 日志：`ema_val_loss` 与 `val_loss` 并列，看两条线的 gap——gap 大说明抖动大，
  影子价值大；gap 收敛说明训练已稳

## 代价与坑

- 多一份模型权重的显存（bf16 影子约 0.3GB）+ 每 N 步一次全量拷贝（同步开销小）。
- 影子是滞后的：训练初期（前几百步）影子不如 raw，别太早信它；过拟合上坡段
  影子一直在变好（sft5 实测 ema 全程单调下行），那是它最高光的时刻。

## 一句话总结

平均弹着点比最好的一发更可信——评测看影子，冠军存影子。
