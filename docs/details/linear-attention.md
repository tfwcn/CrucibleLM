# 线性注意力：O(1) 状态的"金鱼记忆"

> 一句话：不用回看全文，只维护一个固定大小的"状态矩阵"，每来一个 token 更新一次，显存恒定。

## 痛点

标准注意力每步都要看全部历史，计算量随长度平方涨（200K 上下文根本跑不动），
KV 缓存随长度线性涨。MLA 压的是"存"，线性注意力连"算"一起省了。

## 直觉

标准注意力像开卷考试：每道新题都要翻一遍全书。
线性注意力像金鱼：只记住一个"脑内小抄"（状态矩阵 S），新 token 来了，
`S = 遗忘门 × S + 新知识的外积`，答题只看小抄。书可以无限厚，小抄永远 A4 纸。

## 原理

核心递推（每个头一个 `d×d` 状态，d=64）：

```
S_t = decay_t · S_{t-1} + k_t^T · v_t
o_t = q_t^T · S_t / sqrt(d)
```

- `decay_t`（内容相关遗忘门，0~1）：接近 1=记住历史，接近 0=翻篇。
  由输入内容算出来，不是固定值——模型自己决定什么时候忘。
- `k_t^T·v_t`：新知识以"外积"形式写进小抄。
- 训练时可并行：把递推展开成衰减累积矩阵 `D[i,j] = ∏decay`，
  `scores = (QK^T)·D`，一次矩阵乘搞定（O(N²) faster wall-clock，数学等价）。

三处关键思想（Qwen3-Next 系）：

1. **内容相关遗忘门**：门控来自输入，不是学出来的常数；
2. **QK-Norm**：Q/K 归一化，防状态爆炸；
3. **K/V 短卷积**（kernel=3）：给 k/v 加一点局部性（"左右邻居"的信息），
   纯线性注意力太"散"，卷积补局部建模。

## 我们的实现

- 文件：`src/llm/local/linear_attn.py`（`GatedDeltaLite`）
- 训练走并行分支（`D` 矩阵，注意先填 `-inf` 再 `exp`，否则 `0×inf=NaN` 污染梯度，
  见 pitfalls 第 5 条附近的教训）；
- 推理走状态递推 + `(S, k_buf, v_buf)` 三元缓存，O(1)/步；
- 超长（>`linear_chunk=2048`）切块递推，前向精确、反向块内截断（Transformer-XL 式）；
- 短卷积的因果性是血泪教训：必须左补零，`padding=1` 双边补零会让 K/V 偷看
  未来 1 个 token，而训练目标恰是下一 token——模型会学到复制通道，
  loss 虚假塌到 ~0（pitfalls 第 1 条）；
- 解码时卷积尾部必须拼上次的 `buf`（`_step_conv` 取 `buf+current` 末段），
  否则第 3 个 token 起左感受野丢一个真实 token（pitfalls 第 4 条）。

## 从想法到代码

"金鱼小抄"就是三行递推，训练并行版是它的数学展开：

```python
# 解码（O(1)/步）：先衰减旧小抄，再把新知识以外积写进去
new_state = s_prev * decay + k.unsqueeze(-1) @ v.unsqueeze(-2)
o = (q @ new_state) * scale
# 训练（并行等价）：衰减连乘成矩阵，一次算完
d_mat[i, j] = prod(decay[j+1..i])   # 先填 -inf 再 exp，防 0×inf=NaN
scores = (Q @ K.T) * scale * d_mat
```

## 代价与坑

- 状态是定长的，200K 的细节注定记不住——和 MLA 互补（MLA 记梗概准，
  线性记状态便宜），所以才有 Hybrid 交替（见《Hybrid 交替》）。
- 并行分支的 `scale`（`1/sqrt(d)`）在串行/解码/分块三条路径必须一处不落，
  漏一处就是全局偏移（pitfalls 第 5 条）。

## 一句话总结

拿"记不住细节"换"算得动超长"，门控决定记住还是翻篇——线性侧的全部戏都在那扇门上。
