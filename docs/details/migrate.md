# 架构迁移：改结构不重交学费

> 一句话：加深用恒等层、加宽用 Net2WiderNet，输出逐位一致，直接续训——小步验证，大步才走。

## 痛点

128M 训到一半想加到 200M？重训 46 小时+学费全交。迁移工具让你
"接着训"：新结构初始化成和旧模型**逐位一致**的函数，loss 从旧终点起步，
短训恢复。

## 直觉

盖楼加层：新砌的墙先刷成和原来一模一样的颜色（恒等），住户（loss）
毫无察觉，之后再慢慢装修（训练）。Net2WiderNet 是"把一间房隔成两间，
面积分半，总面积不变"。

## 原理与实现

- 文件：`scripts/migrate_model.py` + `src/llm/local/migrate.py`
- **精确操作**（输出逐位一致，可直接 `--init-checkpoint` 续训）：
  - `--add-layers N`：追加恒等层（bert2BERT 式，输出投影置零，
    pre-norm 下恒等）；
  - `--expert-hidden M`：专家加宽（Net2WiderNet，复制单元 + 下投影列平分，
    ulp 级误差内一致）；
- **有损操作**（需短训恢复）：`--keep-layers` 层裁剪；
  `--svd-report` 各投影低秩能量占比（跨架构映射如 GQA→MLA 选 rank 用，
  配 `svd_split` 手册配方，不做假精确的自动映射）；
- `build_block` 是模型/迁移/训练共用的**唯一构造入口**，防参数漂移；
- 复壮手术（`rejuvenate.py`）是同一哲学：恒等式 + 输出不变 + 短训恢复。

## 规则（铁律）

日常迭代（数据/loss/长度/优化器）永远 `--resume`，不动结构；
精确迁移直接续，近似迁移先小步验证（loss 回到旧终点附近再全速）。

## 代价与坑

- 恒等只保输出，不保优化 landscape——加深后梯度路径变了，
  lr 最好减半起步，warmup 重走一小段。
- 迁移只解决"结构"，不解决"分布"：换数据的同时换结构，两个变量一起动，
  出了问题无法归因——一次只动一个。

## 一句话总结

恒等是迁移的灵魂：输出不变，学费不交第二遍。
