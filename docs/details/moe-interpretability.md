# MoE 可解释性：SwiGLU 双负区间与神经网络生长

> 一句话：把专家神经元的激活**按符号区间拆开**看，会发现"双负 echo"污染弱激活统计；
> 顺带给休眠扫描加一道"峰值保护"，并跨 checkpoint 追踪神经元是否在生长——实测本模型
> 双负 echo 真实存在、无死神经元、末段 500 步职责稳定。

## 痛点

两个直觉上的盲区：

1. **"激活大 = 重要"可能被符号骗了**。SwiGLU 的中间激活是 `silu(gate)·up`，当
   `gate<0 且 up<0` 时两负相乘得**正**，输出看起来和"正门×正值"一样强，
   但语义上属于另一条通路（Goodfire 2026 称其为 **double-negative regime / echo**）。
   任何"按 |激活| 排序"的分析（休眠判定、重要性打分、可视化）都会被它污染。
2. **"休眠神经元"未必是永久死亡**。神经元可能随训练沿不同轴生长，今天的弱单元
   可能是明天的强单元——那"重开沉睡单元"的前提就要重新审视。

## 直觉

- 双负像**回声**：真正的正极点（+×+）是"主唱"，双负是同一位置的"回声"。回声通常小，
  但个别神经元的最强响应全是回声——只看幅值会把这些神经元误当成"亮度高的重要单元"。
- 符号区间像**分班点名**：一个神经元对所有 token 的响应混在一起看不出问题，
  按"最强的一批 / 最弱的一批"分开看，才发现最强的几乎是 +×+、最弱的几乎随机。

## 原理

对单个专家神经元 `j`，令 `g = w_gate·x`、`u = w_up·x`，中间激活 `m = silu(g)·u`：

| `g` 符号 | `u` 符号 | `m` 符号 | 区间 |
|---|---|---|---|
| + | + | + | 正门×正值（主极点） |
| + | − | − | 负极点 |
| − | + | − | 负极点 |
| − | − | **+** | **双负 echo**（两负相乘） |

- `silu(g) = g·sigmoid(g)`：`g<0` 时 `silu(g)<0`，故 `silu(g)·u` 在 `g<0,u<0` 时为正。
- 判据：`dn = (g<0) & (u<0)`；只看 `m>0` 的响应，分别统计**全部正激活**与
  **最强 top 1%** 段里 `dn` 的占比。
- 若 `g`、`u` 符号独立同分布，弱激活段 `dn` 占比会趋近 50%（噪声区）；
  明显偏离 50% 才说明有结构。

## 我们的实现与实测

文件：`src/llm/local/interpret.py`（`expert_sign_regimes` 符号区间 / `expert_activation_profile`
激活画像），脚本 `scripts/analyze_experts.py`（`--mode regime|growth|both`）。

### 双负区间（base 预训练权重，12 层 × 17 专家 = 204 专家、39168 神经元）

`data/hq-zh` 取 32 窗 × 512 token，全部专家：

| 指标 | 全局 |
|---|---|
| 双负占**全部**正激活 | **0.583** |
| 双负占**最强 1%** 段 | **0.079** |
| "最强段被双负主导（>50%）"的神经元比例 | **0.0675** |
| "最强单个激活即双负"的神经元比例 | 0.017 |

逐层看，层 0 最重（最强段双负 0.235，echo 主导神经元 20%），层 11 次之（0.128/12.7%），
中间层多在 0.03~0.10。

判读：

- **最强激活偏好 +×+**（最强段双负只占 7.9%，远低于弱激活段的 58%）——与文章"最强尾部
  才是真正的正极点"一致。
- 弱激活段的 58% 只是**比随机基线 50% 略高**，说明双负主要集中在近零的"噪声区"，
  并不代表主特征。
- 但**约 6.7% 的神经元最强响应被双负占据**——和文章"约 4%"同量级。这批神经元是
  任何"按激活幅值"分析的雷区（它们看起来最亮，其实是回声）。
- 口径提醒：这里统计在**全部 token**上（刻画"神经元对什么输入响应最强"），
  未按路由掩码过滤；改成只看路由到的 token 会改变绝对值，但不改"最强段偏好 +×+"的结构。

### 休眠判定的"峰值保护"（`dormancy_masks(..., peak_frac=...)`）

原判据只看神经元**平均** |激活|。新增：平均低于阈值、但**峰值**达到该专家最大峰值
`peak_frac` 倍的神经元**不判休眠**（罕见但强烈 = 被抑制的重要特征，误杀代价高）。默认
`peak_frac=0`（关，opt-in）。

本 checkpoint 实测（`data/hq-zh`）：

| rel_threshold | 休眠占比 | +峰值保护(0.1) | 救回 |
|---|---|---|---|
| 1e-3（默认） | 0.0000 | 0.0000 | 0 |
| 0.4 | 0.0003 | 0.0001 | 6 |
| 0.5 | 0.0032 | 0.0006 | 105 |

判读：真实阈值（1e-3）下本来就**零休眠**（逐专家内最闲神经元仍有该专家均值的
**0.29**，1% 分位 0.57），峰值保护是一条**空转的安全网**；但把阈值调高逼出"休眠"时，
被标记者里约 **84%**（rel=0.5：125→20）其实是"少见但强烈"的单元，会被保护救回——
证明该保护确实在防"按均值误杀"。逐专家口径（现状）与逐层口径实测结论一致
（最闲比值 0.29 / 0.28），故休眠结论对口径不敏感。

### 跨 checkpoint 生长追踪

base 预训练末段 6 个周期 checkpoint（每 100 步，`data/llm-ckpt/ckpt-*`），同 24 窗语料：

| 指标 | 首（step 4800） | 末（step 5300） |
|---|---|---|
| 激活均值（全局） | 0.1999 | 0.1992 |
| 激活峰值（全局） | 6.25 | 6.27 |
| 休眠神经元数（1e-3） | 0 | 0 |
| 逐层归一化激活强度·首末相关 | — | **r = +0.895** |

判读：末段 500 步里激活幅度基本持平、职责高度稳定（r=0.895，约 10% 漂移）、
两端都零休眠——**没有"神经元生长/新长起来"的证据**。注意这**不能**证伪文章的生长
现象：生长是**语义**层面的（"这个神经元从认 diy 到认 do it yourself"），需要显微镜
（feature visualization）；本实验只是幅度/职责代理，且窗口仅训练末段 500 步。诚实标注
为"幅度视角下无生长"。

## 从想法到代码

符号区间统计 = "在 MoE 输入上逐专家重算 gate/up，再分符号段聚合"：

```python
x = moe 输入                       # hook 在 MoE 上取（专家 forward 已不跑）
g = expert.w_gate(x); u = expert.w_up(x)
m = silu(g) * u                    # 中间激活
dn = (g < 0) & (u < 0)             # 双负 echo 掩码
pos = m > 0                        # 只看正极点响应
# 全部正激活里 dn 占比 = dn[pos].mean()；最强 top1% 段同理（先按 m[pos] 排序取头部）
```

生长追踪 = 同一批语料上重复取"逐神经元均值/峰值"画像，跨 checkpoint 比对。

## 代价与坑

- **任何"按 |激活| 排序"的分析都要先分符号区间**：双负让 6.7% 的神经元"看起来最亮"。
  休眠判定用的是均值（弱激活段），受双负影响小；但一旦改成"按峰值/最强激活选重要单元"，
  这 6.7% 就会混进来。
- **峰值保护必须与休眠阈值同口径（逐专家）**：若用"整层最大峰值"做参考，尺度大的层里
  保护阈值被抬高，永远不触发。
- **幅度不是语义生长的代理**：激活均值稳定 ≠ 神经元没在学新东西。想做"生长"必须上
  feature visualization / 归因，本仓库暂无该工具链。
- **分组 bmm 下专家子模块 forward 不被调用**：所有逐专家统计都要 hook 在 MoE 输入上重算
  （与复壮同一坑）。

## 一句话总结

按符号区间拆开看，双负 echo 真实存在（约 6.7% 神经元最强响应被它占据，最强激活仍偏好
+×+）；给休眠判定加一道逐专家峰值保护（高阈值下救回 84% 误杀）；末段 500 步无幅度增长、
无死神经元、职责稳定——可解释性工具链已就位，语义级"生长"仍待显微镜。
