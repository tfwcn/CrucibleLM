# 归一与激活：RMSNorm / QK-Norm / SwiGLU

> 一句话：三处"稳定器"——归一防爆炸、门控给表达力，小模型训练不崩全靠它们。

## 痛点

深网训练最怕数值飞：某层输出突然大 100 倍，梯度跟着炸，loss 一夜回到解放前。
128M 虽小，12 层 + MoE 路由 + 混合精度，炸点一点不少。归一化就是每层的
"稳压器"。

## 直觉

- **RMSNorm**：不管均值，只把"能量"（均方根）缩到 1，再乘个可学系数。
  比 LayerNorm 少算均值、少一堆参数，又稳又快——现在基本是标配。
- **QK-Norm**：Q 和 K 点积前各归一一次。点积是"相似度× magnitudes"，
  某个头 magnitude 一飘，softmax 直接塌成 one-hot，梯度也没了。
  先归一，相似度就是纯余弦，塌不了。
- **SwiGLU**：FFN 里 `silu(gate) × up`，门控结构——表达力比 ReLU 强一档
  （门决定"过不过"，值决定"过多少"），代价是 3 个矩阵（参数×1.5，
  MoE 里最费的就是它）。

## 原理

```
RMSNorm(x) = x / sqrt(mean(x²) + eps) × w
QK-Norm:   q, k = RMSNorm(q), RMSNorm(k)   # 点积前
SwiGLU(x)  = silu(x·Wg) × (x·Wu)  →  (·Wd)
```

RMSNorm 内部用 fp32 求方差（`mla.py` 注释写了），混合精度下不丢精度——
半精度求平方和容易溢出/欠精，这是个经典暗坑，我们的实现默认就是对的。

## 我们的实现

- 文件：`src/llm/local/mla.py`（`RMSNorm`，全库共用）、各注意力/QK、MoE 专家
- 初始化配合：残差分支的输出投影用小方差（`0.02/sqrt(2N)`，GPT-2 式），
  embedding 小方差——归一 + 小初始化双保险，loss 起步才不爆炸

## 代价与坑

- RMSNorm 的 `weight` 全 1 初始化，别手贱改小——它是"缩放"不是"衰减"。
- 半精度推理（`dtype="bf16"`）安全，正是因为 RMSNorm 内部走了 fp32；
  如果哪天自己写 norm，记得把这行抄上。

## 一句话总结

稳压器三件套，存在感越低越成功——训练没炸，就有它们一份功劳。
